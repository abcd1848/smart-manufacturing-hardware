# Arduino 기반 전자부품 자동 검사·분류 시스템 하드웨어 제어

컨베이어 벨트 위의 전자부품을 AI 비전으로 검사하고, 판정 결과에 따라 서보모터를 이용해 자동으로 분류하는 제조 검사 시스템입니다.

Arduino MEGA 2560을 기반으로 컨베이어 모터, 적외선 센서, 서보모터, 비상정지 버튼 및 부저를 제어했으며, PC와의 시리얼 통신을 통해 검사 결과와 제어 명령을 전달받도록 구현했습니다.

---

## Project Overview

전자부품이 컨베이어 벨트를 따라 이동하면 적외선 센서가 부품의 위치를 감지합니다.

부품이 검사 위치에 도착하면 컨베이어를 일시 정지시키고, PC의 AI 비전 시스템에서 부품의 상태를 검사합니다.

검사 결과는 정상, 불량 또는 판정 불가로 구분되며, Arduino가 전달받은 판정 결과에 따라 각 위치의 서보모터를 동작시켜 부품을 자동으로 분류합니다.

## System Operation

1. 컨베이어 벨트가 전자부품을 검사 위치로 이동시킵니다.
2. 적외선 센서가 전자부품의 도착 여부를 감지합니다.
3. 부품이 검사 위치에 도착하면 컨베이어를 일정 시간 정지시킵니다.
4. PC의 AI 비전 시스템이 전자부품의 상태를 검사합니다.
5. PC가 정상, 불량 또는 판정 불가 결과를 Arduino로 전달합니다.
6. Arduino가 검사 결과에 해당하는 서보모터를 동작시킵니다.
7. 전자부품을 각 결과에 맞는 위치로 자동 분류합니다.
8. 분류가 완료되면 컨베이어를 다시 구동하여 다음 부품을 검사합니다.

## Main Control Functions

### Conveyor Control

DC 모터와 모터 드라이버를 이용해 컨베이어 벨트를 구동했습니다.

PWM 제어를 적용하여 컨베이어의 이동 속도를 조절하고, 적외선 센서가 부품을 감지하면 컨베이어를 일정 시간 정지시킨 뒤 다시 동작하도록 구현했습니다.

### Object Detection

여러 개의 적외선 센서를 사용하여 전자부품의 이동 위치와 검사 위치 도착 여부를 감지했습니다.

센서값을 기반으로 컨베이어 정지 시점과 서보모터 동작 시점을 제어했습니다.

### Automatic Sorting

PC에서 전달받은 AI 검사 결과에 따라 각 분류 위치의 서보모터가 동작하도록 구현했습니다.

전자부품이 분류 위치에 도착하는 순간 서보모터가 작동하여 정상, 불량 및 판정 불가 부품을 각각 분리합니다.

### Emergency Stop

비상정지 버튼 입력이 감지되면 컨베이어와 서보모터의 동작을 즉시 중단하도록 구현했습니다.

비상정지 상태에서는 부저를 통해 작업자에게 시스템 이상 상태를 알립니다.

### Serial Communication

Arduino와 PC 사이의 시리얼 통신을 구현하여 AI 검사 결과와 하드웨어 제어 명령을 송수신했습니다.

JSON 형식의 데이터를 사용해 명령, 컨베이어 속도, 센서 상태 및 환경 데이터를 전달하도록 구성했습니다.
